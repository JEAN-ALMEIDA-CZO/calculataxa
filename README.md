## 🚀 Funcionalidades

- Entrada do valor da conta.
- Entrada da taxa de serviço (%).
- Exibe valor da taxa e total com a taxa incluída.
- Responsivo e fácil de usar.

## 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
